# 합력하여 선을 이루는 기도

얼굴을 몰라도 전 세계 성도가 서로를 위해 중보기도하고, 나의 기도 생활을 관리하는 모바일 웹앱(PWA)입니다.

## 지금 있는 메뉴 (첫 버전)
- **홈**: 오늘의 말씀(롬 8:28), 오늘 기도 출석, 연속 기도일, 최근 7일 기도 시간, 최근 기도 요청
- **중보기도**: 개인 중보기도 / 선교지에서 온 편지 / 나라와 열방 / 미자립교회 / 릴레이 기도 게시판, 검색, "함께 기도할게요", 댓글, 신고, 익명 글쓰기
- **기도 다이어리**: 기도 제목(내용, 작정 기간, 출석, 응답 메모, 중보기도 요청 연동) / 기도 시간(하루 누적 추가, 기간 설정) / 기도 편지 / 스크랩
- **간증**: 간증 글쓰기, 아멘, 댓글, 신고
- **사연&고민**: 공개 범위(상담사 / 목회자·선교사 / 일반 성도)를 고른 사람만 답글
- **기도란** (오른쪽 위 메뉴): 기도의 모든 것, 나만의 기도 노하우
- **내 정보** (오른쪽 위 사람 아이콘): 닉네임, 구분

## 다음에 추가할 메뉴
라이브 중보기도 방송, 회원 가입과 서버(다른 성도와 실제로 글 공유)

## 구조
- `app.html`: 앱 본문 (화면, 디자인, 동작 모두 이 파일 하나)
- `build.sh`: `app.html`을 감싸 설치 가능한 `index.html`을 만듭니다
- `manifest.json`, `sw.js`, `icon.svg`: 휴대폰 홈 화면에 설치하기 위한 파일

현재는 기록이 각 기기 브라우저에만 저장됩니다.
